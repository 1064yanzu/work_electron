# 与"邻近"风格的差异（避免混淆）

这套风格容易和几个相似的设计语言混淆，但**细节差异决定高级感**。下表帮你快速对位。

| 维度 | B.AI / Claude.ai | Vercel / Linear | OpenAI ChatGPT | Notion |
|---|---|---|---|---|
| **背景基调** | 暖奶油 `#FAF9F5` | 冷白/纯白 `#FAFAFA` `#fff` | 中性灰白 `#F7F7F8` | 暖白 `#fff` |
| **文字色** | 暖黑 `#1A1A19` | 冷黑 `#0A0A0A` | 中黑 `#202123` | 暖黑 |
| **描边色调** | 暖灰 `#E8E5DD` | 冷灰 `#E4E4E7` | 中灰 `#E5E5E5` | 暖灰 |
| **彩色策略** | 1% 点缀（头像/工具图标） | 几乎纯单色 | 紫绿点缀（GPT/Plus） | 多彩 emoji |
| **圆角偏好** | 全胶囊 `rounded-full` | 中等 `rounded-md/lg` | 中等 `rounded-xl` | 小 `rounded-md` |
| **字体** | Inter + PingFang | Inter / Geist | Söhne | Inter |
| **图标 stroke** | 1.5px | 1.5-2px | 2px filled | 多样 |
| **阴影** | 几乎无 | 极轻 | 无 | 中等 |
| **logo 风格** | 自定义 mark 字符 | 几何图形 | 三叶花瓣 | emoji 风 |

## 核心判断标准

**问自己一个问题：用户在屏幕上盯 1 小时累不累？**

- B.AI/Claude 的暖底是为了"长时间阅读舒适"——AI 对话场景特化
- Vercel/Linear 的冷底是为了"专业感、效率感"——开发者工具特化

如果你的产品是"陪用户聊天/思考"，选 B.AI 风。
如果你的产品是"快速操作/效率工具"，选 Vercel 风。

## 一个快速识别 trick

看截图右上角的**用户头像**：
- 头像是**彩色渐变球**（多色、有光泽）→ B.AI / Claude.ai 系
- 头像是**纯色字母圆**或灰色剪影 → Vercel / Linear 系
- 头像是**真实照片** → 社交/通用产品

这个差异看似微小，但实际上是整套设计哲学的体现：B.AI 系刻意用一个"彩色的人"对抗"单色的界面"，营造温度感。
